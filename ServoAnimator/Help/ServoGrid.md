# Servo Editing

The old Servo Grid has been replaced by the Commands pane beside the URDF.

Use Add or Edit in Commands to choose a servo or individual child control and adjust its value, speed and Disable state. The Spline checkbox beside the Servo picklist enables sequence-wide interpolation for supported whole-servo targets.

Use the URDF pose editor and the timeline's Insert Pose action to capture an entire pose. The former Generate commands from grid values action has been removed.

Numeric ranges and physical calibration are unchanged. Live Drive controls whether preview edits are also sent to connected hardware.
