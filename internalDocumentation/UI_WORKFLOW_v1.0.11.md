# Animation Editor & Player v1.0.11

UI sizing/readability maintenance release.

- Added `using System.ComponentModel;` to `LibraryItemSelectionWindow.xaml.cs`.
- Increased the collapsed Sequence Description field height from 24 to 34 pixels.
- Increased the Animation Library Search field height from 25 to 34 pixels.
- Added a darker, higher-contrast DataGrid column-header style to the Animation Library browser.
- Widened Servo Configuration Direction, PWM, Speeds, and Accels columns to prevent clipping.
- Increased the Servo Configuration default window width to 1180 pixels.
