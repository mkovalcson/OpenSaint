# Animation Editor & Player v1.0.12

## Changes

- URDF preview/editor controls are independent of Live Drive; Live Drive only enables output to connected physical hardware.
- Servo Speed selectors widened.
- Sequence Description-line buttons reduced in height and SEQUENCE badge vertically centered.
- Sequence/Movie filename indicators omit extensions.
- Timeline command markers changed from plus signs to shallow downward triangles, with automatic vertical staggering and position-aware selection when markers overlap.
