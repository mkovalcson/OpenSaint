# Animation Editor & Player v1.0.10

## Top editor layout

- The top editor area is split into equal left and right halves.
- All collapsible servo groups are stacked in the left half in this order:
  1. Eye Flaps
  2. Nose
  3. Eyes
  4. Neck
  5. Lighting & Vents
  6. Eye Pop
  7. Headtop Controls
- Headtop Controls still defaults to collapsed and retains the internal MFR / Whip Antenna / Microphone divider lines.
- The live URDF Robot Head is embedded in the right half of the main editor.
- The Robot Head is no longer opened automatically as a separate window. View > Robot Head can still open an optional detached copy.
- The embedded and detached Robot Head views receive the same timeline, spline, Live Drive, mouth-amplitude, and RGB eye-color updates.
- Expanded Sequence and Movie descriptions occupy only the left editor half so the URDF view remains visible.
